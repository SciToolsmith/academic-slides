# 毕业答辩叙事设计

本参考适用于本科、硕士和博士毕业答辩。用论文的证据结构决定叙事，不把所有学科压进同一套工程流程图。

## 首先确定一句话主张

用一句可辩护的话概括：研究了什么、采用了什么关键路径、得到什么主要发现、为何可信或有价值。后续页面必须服务于这句话；无法连接到主张且不承担答辩防守作用的内容移至附录或删除。

## 学位层次侧重

| 层次 | 默认答辩重点 |
| --- | --- |
| 本科 | 任务完成度、基本方法、结果可信性、个人工作与反思 |
| 硕士 | 清晰研究问题、方法或应用改进、验证深度、创新点与边界 |
| 博士 | 原创问题、理论或方法贡献、多层证据、可推广性与适用边界 |

这是默认侧重，不是固定章节表。院校要求或用户要求优先。

## 按证据结构组织主体

### 论证驱动 `argument_driven`

常见链条：问题语境 → 概念/理论框架 → 材料与方法 → 核心命题 → 文本、史料或案例证据 → 反例与边界 → 贡献。

优先使用短引文对照、概念关系图、案例矩阵、时间线和证据链。不要把并列观点伪装成流程。

### 实证驱动 `empirical`

常见链条：问题与假设 → 数据/样本 → 变量和识别策略 → 核心结果 → 稳健性或异质性 → 解释 → 贡献与限制。

优先使用可复核图表、效应量、置信区间和简洁模型定义；避免堆放完整回归表。

### 实验驱动 `experimental`

常见链条：假设 → 实验设计 → 控制与测量 → 主要结果 → 不确定性/误差 → 复现或验证 → 机制解释。

优先呈现实验装置、条件对照、测量流程、误差来源和结果曲线。

### 设计驱动 `design_driven`

常见链条：需求与约束 → 基准方案 → 关键设计/优化 → 建模或实现 → 结果 → 多维验证 → 性能收益与工程边界。

优先呈现系统结构、几何或机构图、优化前后对比、关键公式、仿真与实验互证。

### 混合型 `mixed`

按主研究问题组织，而非按方法各自成章。明确哪种证据回答哪一个子问题，并用综合页合并结论。

## 页数与可选时长是近似预算

页数策略未指定时询问用户选择 `auto`（推荐）或 `fixed`；用户选择 `auto` 后，根据论文证据结构、学位层次和叙事需要确定页数，不为填满时间或套用布局库而增页。

用户主动提供时长时，将其约 90% 作为预计讲述预算，保留翻页、停顿和现场缓冲。未提供时不询问、不虚构默认时长。以下仅在已知时长时用于初步估算：

- 图像、实验或工程设计页：约 42–50 秒；
- 数据、实证或均衡型页面：约 50–60 秒；
- 理论、文本和论证型页面：约 60–75 秒；
- 封面、目录、章节过渡与结束页通常更短。

不要承诺精准计时。稿件语速、术语难度、演示习惯和现场互动会改变实际时长。生成后以口头试讲为准调整。

当用户同时指定固定页数和时长时，计算近似的“可用讲述秒数 ÷ 正文页数”。明显偏离相应证据结构的合理区间时提出风险与推荐值，但若用户坚持则尊重其选择。

## 章节比例

默认把最多时间留给结果、验证和贡献。可从下列范围开始，再按论文调整：

- 背景、问题与缺口：15%–22%；
- 理论、方法、系统或研究设计：20%–30%；
- 结果与验证：35%–50%；
- 贡献、局限、展望与总结：10%–18%。

论证驱动论文可提高概念框架和证据解释比例；设计驱动论文可提高方案、优化与验证比例。不得机械追求百分比总和的形式整齐。

## 自适应章节与导航

先根据论文的论证链生成章节，再决定是否需要目录和章节首页。不得从模板反推“固定五部分”，也不得为了填满顶部导航而拆分或合并研究内容。

- 章节数、名称和顺序由研究问题、证据结构、学位层次、院校要求与用户已提供的近似时长共同决定。
- 很短且线性的汇报可以省略目录和独立章节首页；只有一至两个主体单元时，正文使用当前章节标签即可。
- 三至六个一级章节通常适合单页目录与完整分段导航，但这只是易读区间，不是内容约束。
- 七个及以上确有必要的一级章节，可缩短导航标签、改用“当前章节 / 总章节数”标签，或把目录拆成两页；不得静默丢弃章节。
- 章节首页只用于重要叙事转折。连续的短章节可用正文页标题和导航高亮完成过渡。
- 目录、章节首页、正文导航必须来自同一份 `sections` 数据，避免名称和顺序漂移。

## 单页内容原则

- 一页承担一个主要沟通任务。
- 标题尽可能写成结论，而非“研究结果”“模型分析”等空泛标签。
- 先给结论，再给证据和解释。
- 同一关键数字在全稿保持单位、精度和口径一致。
- 方法只讲理解结果所必需的信息；完整推导和次要参数放附录。
- 贡献页必须回指前面展示过的结果，避免首次提出没有证据的新主张。
- 局限页说明适用边界和未来验证，不用空洞套话。

## 公式决策

公式满足至少一项才进入正文：定义核心模型、目标函数或约束；直接解释关键结果；体现核心方法贡献；缺少它会妨碍评委理解；很可能成为追问对象。

每页通常一个主公式，最多两个紧密相关的公式。必须同时说明：

- 公式衡量或约束什么；
- 需要解释的关键变量；
- 本研究改变或估计了什么；
- 公式怎样连接到本页结论。

不要凭记忆改写符号或展示无法在本页解释的大段推导。渲染、兼容回退和安全边界统一遵守 `references/asset-preparation.md`，不得把 raw LaTeX 命令直接放上页面。

## 流程图决策

仅在存在三个以上连续步骤、明确输入/处理/输出、分支反馈、循环迭代或模块依赖时绘制。并列观点优先使用列表、矩阵或分组；已有清晰论文原图时优先引用原图。

根据关系选择时间线、过程流、系统结构、因果链、比较矩阵或闭环图，不默认使用相同的方框箭头图。

## 主稿与附录

主稿回答“问题是什么、怎么做、发现了什么、为何可信、贡献是什么”。附录用于：

- 完整公式推导、额外稳健性检验和参数表；
- 备用案例、次要结果和实现细节；
- 伦理、数据处理、实验校准或系统边界；
- 预判评委追问所需的证据。

附录页同样需要来源和可读布局，不应成为未经整理的截图仓库。
