# 论文章节与编号

本参考规定组会文献汇报的固定导航结构。它约束目录、论文顺序和正文左上角标题，不限制每个章节的实际页数或证据布局。

## 单篇与多篇

- `single_paper`：封面后直接进入第一篇论文正文，不生成目录页。论文分隔页默认也省略，除非用户明确要求保留。
- `multi_paper`：封面后必须生成目录，目录按 `focal_paper_ids` 的一基顺序列出每篇焦点论文。目录只展示论文级条目，不展开 `1.1`、`1.2` 等子章节。
- 多篇模式中，每篇论文正文前使用一张 `paper-divider`，序号与目录一致，如 `01`、`02`、`03`。
- 背景文献、方法资料和补充材料不参与论文序号计算。

## 每篇论文的固定标题

焦点论文按下列语义顺序展开，其中 `X` 是论文序号：

1. `X.1 文献基本信息`：必须。核对题名、作者、来源、年份、标识符和一句贡献。
2. `X.2 研究背景与意义`：必须。说清已知、缺口、研究问题和阅读价值。
3. `X.3 研究设计与方法`：必须。根据论文类型呈现实验、数据、模型、文本、案例或理论论证的证据生成方式。
4. `X.4 主要结果与结论`：必须。展示原论文的核心证据，并说明它支持什么、不支持什么。
5. `X.5 批判性思考与启示`：可选。只在有证据支撑的局限、可替代解释、迁移价值或验证计划值得独立成页时使用。

不得把“研究结果第二页”误编成 `X.5`。章节号表示语义章节，不表示页码。

## 跨页与标题渲染

- 正文页左上角必须显示完整标题，如 `1.2 研究背景与意义`或 `2.4 主要结果与结论`。
- `content.title` 写入上述完整标题；页面的具体结论放在 `takeaway`、图表标注或正文内，不得替换固定章节标题。
- 一个语义章节可以拆成多页。所有续页重复同一个 `X.Y` 和章节名；需要时在右侧或页脚显示 `1/3`、`2/3`、`3/3`，不改变左上角编号。
- 同一章节的页必须相邻。首次出现顺序必须为 `.1 → .2 → .3 → .4 → .5`，但不强求每章页数相等。
- 跨论文综合、讨论和后续行动放在所有论文块之后，不得伪装成新的焦点论文。

## Deck spec 约定

- 论文顺序以 `literature.focal_paper_ids` 为唯一基准。
- 目录页使用 `paper-agenda`，并在 `render_data.papers` 中按论文顺序写入 `number`、`title` 和可选 `detail`。
- 多篇论文分隔页使用 `paper-divider`，并在 `render_data.paper_no` 写入两位编号。
- 每张论文正文页在 `render_data.paper_no` 写入一基论文序号，便于导航与后续校验。
- 续页可在 `render_data.continuation` 中写入 `index` 和 `total`；它只是页内导航，不参与章节编号。
